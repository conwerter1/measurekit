# MeasureKit — Android-приложение для измерений

Это нативное Android-приложение на Kotlin + Jetpack Compose, цель которого — заменить ARCore-приложения на устройствах MediaTek (где ARCore не работает). Целевое устройство — Xiaomi 12T (MediaTek Dimensity 8100-Ultra, Android 15, экран 6.67", 2712×1220, 446 ppi).

## Архитектура

- **Kotlin + Jetpack Compose** (Material 3, dynamic theming)
- **CameraX 1.4.0** — для фото-режимов и дальномера
- **Room 2.6.1** — локальная история измерений
- **Navigation Compose 2.8.4** — между экранами
- **minSdk = 26** (Android 8.0+), **targetSdk = 34**, **compileSdk = 34**, **JVM 17**

## 4 модуля измерения

### 1. Линейка (ruler)
Виртуальная линейка на экране для измерения мелких предметов прикладыванием. Калибровка под 446 ppi (12T) с возможностью ручной коррекции по кредитке (85.60×53.98 мм).

### 2. Фото с эталоном (photo)
- Фото объекта вместе с эталоном известного размера (монета, лист А4, линейка)
- Пользователь указывает 2 точки эталона + его реальный размер
- Затем ставит точки на объекте → получает размеры
- Опционально: 4-точечная гомография для перспективной коррекции (объект и эталон в одной плоскости)

### 3. Площадь (area)
- Те же 2 точки эталона
- Полигон из произвольного числа точек
- Расчёт площади (формула шнурующих) и периметра

### 4. Дальномер (rangefinder)
- Ввод высоты прибора над землёй (h)
- Наводка на основание объекта
- Угол наклона из SensorManager (TYPE_ROTATION_VECTOR)
- Расстояние = h / tan(angle_below_horizon)
- Точность ±5–10% на 2–20м, требует горизонтальной поверхности

### 5. История (history)
- Все измерения в Room: тип, значение, единицы, время, опционально превью фото
- Экспорт в CSV или текст

## Замечания и принципы

- **Русский UI**, формат вывода — метрический (мм, см, м, м²)
- **Без внешних SDK кроме AndroidX/CameraX/Room** — приложение должно работать оффлайн
- **Без Internet permission** — приложение полностью локальное
- **Тёмная и светлая темы** через `dynamicColor` (автоматически на Android 12+)
- **Точность измерений** — честно показывать пользователю, что это бытовой инструмент, не для критической инфраструктуры
- **Сохранять состояние** при повороте экрана (rememberSaveable / ViewModel)
